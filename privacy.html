Privacy, without the mystery.

Our image and file utilities operate directly in your browser. When you select an image to compress, crop, resize, inspect, convert or turn into a PDF, the file data stays on your device and is not sent to Utility Platform servers. Text and calculator inputs are also processed on your device.

The tools use browser APIs such as Canvas, File, Blob and Crypto to process the input. Temporary local preview and download links are released when you leave the page.

We do not require an account or use file-processing APIs. Some PDF tools download pinned pdf-lib and PDF.js JavaScript libraries from jsDelivr. This CDN can receive resource-request metadata but does not receive your selected file contents through our application. We use Cloudflare Web Analytics to understand page visits and site performance through a browser-based analytics beacon. Cloudflare receives website usage and performance information, but not the image files you select or process. See Cloudflare Web Analytics documentation for details. Hosting infrastructure may also process ordinary HTTP request metadata such as IP addresses and user agents in its server/CDN logs.

Browser downloads are saved according to your browser settings. Please do not rely on these utilities as a substitute for reviewing the upload requirements of any third-party application.

We will update this policy if our hosting, analytics, or tools change. Last updated: October 20, 2026.
