Encode and decode URL parameter values

Enter a string, then choose to encode or decode a URL component. The utility handles special characters such as spaces, ampersands and question marks in query values.

Example and important limitation

For example, encode “hello & welcome” before placing it in a query parameter. This is component encoding, not a complete URL builder; avoid encoding an entire address unless that is what your application expects.
