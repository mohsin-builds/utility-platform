Select JPG, PNG or WebP files in the order you want them to appear, then choose Generate result. Each picture is placed on its own A4 PDF page with margins.

Example and important limitation

For example, combine scanned receipt images or photographed worksheets into one document. The current tool supports up to 20 images and produces image-based pages; it does not perform OCR or create searchable text.
