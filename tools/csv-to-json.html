Turn CSV rows into JSON objects

Paste comma-separated values with a header row. The first row becomes the set of object keys, and following rows become JSON objects. Quoted commas and escaped quotes are supported.

Example and important limitation

For example, convert a small contact list into JSON for a script. Values remain text strings; inspect blank headers and missing cells before importing the result.
